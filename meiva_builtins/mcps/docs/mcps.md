# Built-in MCP integrations

`meiva_builtins/mcps/` contains the repository's bundled server definitions and
supporting packages. The current bundled integration is
[Chrome MCP — native Chrome + chrome-devtools-mcp upstream](chrome/chrome.md) for browser automation.

Discovery, configuration, installation and transport contracts belong to
[MCP Integrations](../../../docs/mcps/mcps.md). Installed external servers are not bundled packages.
