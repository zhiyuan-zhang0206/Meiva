# File-only Dream sources

The user ruled that every provenance source must be a real file. External URLs and dated oral rulings must first be captured in a file, including a URL with context when a content dump is unavailable. This replaces semantic provenance prefixes and the external-probe queue with one file-resolution rule.

Pool-relative references use the memory alias. Existing optional repository mappings remain machine-dependent. Markdown evidence remains a normal recursively indexed note; other formats remain attachments.
