# Decide attention before routing

The communication audit found that displayed sampled messages were explicitly
marked for display by their authors. Existing core guidance already discouraged
routine narration. Fleet instructions could still be read as requiring direct
user delivery whenever work completed without a delegator. Changing capture or
unread mechanics would have hidden that ambiguity and risked losing important
answers.

We place user benefit before recipient and transport selection. Completion,
errors and standing responsibilities do not independently justify an interruption;
requested results, needed decisions, changed commitments and corrections remain
visible. A truthful internal error trace need not become a user update when the
outcome and promises are unchanged. Peer reporting obligations remain useful for
coordination without implying publication to the human.

One shared policy is composed into each delivery mode. Queueing is still an
attention cost, so queue versus emergency push is a later decision. We rejected
keyword filtering, automatic read/quiet flags and a new classifier because the
evidence pointed to author instructions, while those mechanisms could suppress
important messages. Naive ordinary text has no hidden-label mechanism; instructions
must state that limit rather than promise concealment.

Constructed paired cases and prompt assembly checks establish instruction
coverage. They do not establish model adherence rates. Natural behavior after an
independently authorized rollout remains the evidence for that question.
