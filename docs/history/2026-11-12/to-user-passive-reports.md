# To-User passive reports

To-User reports use Markdown with clickable links. Rendered workspace views are
limited to Markdown, images and videos. HTML opens as source and downloads with
a passive CSP, removing script execution from this user communication surface.
The prior script-only sandbox supported interactive reports; removing that path
keeps the report format consistent with the Markdown overview. Audio and PDF
binary recognition remains so these files offer download without text decoding.
