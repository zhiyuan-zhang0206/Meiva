# Workspace memory promotion

Private notes need a review identity independent of modification dates. A content hash ledger records local-only decisions and promotions, allowing historical unreviewed material to enter Dream without repeatedly reviewing unchanged notes.

Cross-host collection uses explicit JSON exports rather than implicit network access. Scope-trap scoring is a deterministic prioritization signal; the arbiter verifies meaning and shared coverage before promotion. Private pruning is an explicit source-host action after the canonical shared target exists.
