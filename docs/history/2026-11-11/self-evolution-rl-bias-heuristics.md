# Self-evolution RL bias diagnosis and mitigation

Recurring corrections in persistent multi-agent work need a remedy selected at
the smallest sufficient layer. We added diagnostic hypotheses and a top-down
mitigation ladder to the self-evolution playbook, with detailed guidance in a
linked reference so routine trace collection keeps a compact entrypoint.

The decision separates declarative Memory from reusable Skill procedures and
uses threshold-gated schedules for repeatedly missed hygiene. An isolated Plugin
is the last step when a new service surface is required; case-specific Core
primitives are excluded. Training explanations remain hypotheses to verify
against traces, and mechanisms retain existing authority and cleanup boundaries.

The requested taxonomy was checked by static review and documentation lints.
No model replay comparison was performed, so this record makes no measured
behavioral-improvement claim.
